# assets — макеты упаковки

Сюда кладутся макеты или фото пачек. Сайт подхватывает их сам — код
править не нужно.

## Имена файлов

| Файл | Товар |
| --- | --- |
| `seeds` | семечки Pista Tuzli |
| `kurt-cube` | курт кубиками |
| `kurt-ball` | курт шариками |
| `kurt-stick` | курт палочками |
| `sticks` | сырные палочки |
| `braid` | сырная косичка |

Расширение `.png` или `.jpg` — например `kurt-cube.png`.

## Если у вас PDF от типографии

Кладите PDF как есть, с любым именем — он будет переведён в PNG нужного
имени и размера. Форматы AI и CDR браузер не читает: их нужно сначала
экспортировать в PDF или PNG (это умеет любая типография в один клик).

## Что должно быть на картинке

Только **лицевая сторона пачки**, ровно, без фона и перспективы. У
флоу-паков (курт, сыр) прозрачное окно на макете можно оставить пустым —
продукт внутри рисуется трёхмерным.

Если макетов нет, подойдёт фото: пачка на белом фоне, снятая строго
сверху, без вспышки и наклона.

## Пока файлов нет

Этикетки рисуются в браузере по данным из `PRODUCTS` в `index.html`.
Сайт не сломается, если папка пустая.
