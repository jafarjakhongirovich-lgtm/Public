# Porsche 911 GT3 RS (992) — 3D-презентация

Интерактивная презентация на 10 разделов с анимированной 3D-моделью и полными
техническими характеристиками Porsche 911 GT3 RS поколения 992.

Всё работает без интернета и без внешних библиотек: 3D-движок, модель автомобиля
и вся анимация написаны с нуля на обычном Canvas 2D.

## Запуск

Откройте `index.html` в браузере — это один самодостаточный файл (~78 КБ).

## Что внутри

**3D-сцена.** Собственный рендерер: перспективная проекция, отсечение задних
граней, сортировка методом художника, плоское затенение с основным и заполняющим
источниками света, зеркальные блики, отражение на полу и мягкая контактная тень.

**Модель автомобиля** построена процедурно по заводским габаритам
(4572 × 1900 × 1322 мм, база 2457 мм): кузов из 20 поперечных сечений с вырезами
колёсных арок, антикрыло с подвесом «лебединая шея», колёса 20″/21″ с суппортами
и центральной гайкой, сплиттер, диффузор, жалюзи моторного отсека,
оппозитная «шестёрка» для режима разреза.

**Разделы:** титул · двигатель · динамика · аэродинамика · шасси и тормоза ·
масса и материалы · габариты · Нюрбургринг · Weissach и цены · сводная таблица.

**Интерактив:** прокрутка со снапом, стрелки и клавиатура, вращение сцены мышью
или пальцем, шесть цветов кузова, кнопка DRS, тахометр до отсечки 9000 об/мин,
счётчики и диаграммы, габаритные выноски поверх 3D.

## Разработка

Исходники разложены по модулям в `src/`, сборка склеивает их в один файл:

```
node build.js
```

| Файл | Назначение |
|---|---|
| `src/engine.js` | 3D-движок: векторы, матрицы, меши, рендер |
| `src/car.js` | Геометрия автомобиля и материалы |
| `src/app.js` | Камеры слайдов, анимации, интерактив |
| `src/body.html` | Разметка и содержание разделов |
| `src/style.css` | Оформление |
| `build.js` | Сборка `index.html` и `dist/artifact.html` |

## Об источниках данных

Характеристики приведены по заводским данным Porsche для 992 GT3 RS (2022–2023).
Расход и выбросы — по циклу WLTP; цены указаны на момент премьеры и различаются
по рынкам и комплектациям. 3D-модель — стилизованная реконструкция пропорций
кузова по заводским габаритам, а не точная копия геометрии автомобиля.
