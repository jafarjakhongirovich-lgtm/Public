# 3D Presentation Agent

Агент для Claude Code, который собирает **анимированную 3D-презентацию** из темы,
конспекта или готового документа. На выходе — один HTML-файл: камера летит сквозь
3D-сцену от слайда к слайду, у каждого слайда свой анимированный объект.

## Как пользоваться

Просто попроси в Claude Code:

```
сделай презентацию про переход на микросервисы, 7 слайдов
собери деку из docs/roadmap.md, тема ember
```

Агент подхватится сам (или вызови его явно как `3d-presentation`), напишет
структуру, соберёт файл и проверит его в браузере.

Живой пример — [`example.html`](example.html): открой двойным кликом.

## Управление презентацией

| Клавиша | Действие |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd>, клик, скролл, свайп | листать слайды |
| <kbd>N</kbd> | заметки докладчика |
| <kbd>F</kbd> | полный экран |
| <kbd>Home</kbd> / <kbd>End</kbd> | первый / последний слайд |
| `#3` в адресе | ссылка на конкретный слайд |

Печать даёт плоскую текстовую версию — по слайду на страницу.

## Что внутри

```
.claude/agents/
├── 3d-presentation.md              # сам агент: схема, правила, процедура
└── 3d-presentation/template.html   # движок на Three.js
```

Движок готов и оттестирован. Агент правит в копии шаблона **только блок
`const DECK = {...}`** — заголовки, тезисы, цифры, тему и заметки. Логику камеры
и сцены он не трогает.

### Раскладки слайдов

`title` — титульный · `content` — текст слева, объект справа · `stats` — цифры ·
`full` — объект во весь экран · `quote` — цитата.

### 3D-объекты

`particles` · `network` · `globe` · `bars` · `helix` · `knot` · `waves` · `grid` ·
`cubes` · `rings` — выбираются по смыслу слайда, а не по красоте.

### Темы

`midnight` (по умолчанию), `aurora`, `ember`, `deep sea`. Две краски — `accent` и
`accent2` — перекрашивают сразу и текст, и 3D-объекты, и прогресс-бар.

## Требования

Three.js подгружается с CDN по import map, поэтому **при первом просмотре нужен
интернет**. Без него страница честно деградирует в аккуратную статичную текстовую
деку и показывает об этом пометку. Для гарантированно офлайнового файла Three.js
можно вшить внутрь — как именно, описано в конце `.claude/agents/3d-presentation.md`.
