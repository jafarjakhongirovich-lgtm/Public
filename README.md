# Jarvis

Личный ассистент в Telegram на **Claude Agent SDK**, работающий через вашу
подписку Claude — без API-ключа и без оплаты за токены.

## Как устроена авторизация

Agent SDK не ходит в API сам: он запускает локальный Claude Code CLI, а тот
берёт OAuth-токен из `claude auth login`. То есть бот использует ровно ту же
авторизацию, что и ваш `claude` в терминале — вашу подписку.

Единственное, что может это сломать — переменная `ANTHROPIC_API_KEY` в
окружении: при ней CLI переключится на оплату по ключу. Поэтому `jarvis`
снимает `ANTHROPIC_API_KEY` и `ANTHROPIC_AUTH_TOKEN` при старте и пишет об
этом в лог.

> Подписочный вход разрешён для вашего личного использования. Раздавать доступ
> к такому боту посторонним нельзя — поэтому `JARVIS_OWNER_IDS` обязателен, и
> всем остальным бот просто отказывает.

## Установка на Windows — одним щелчком

Двойной щелчок по **`install.bat`**. Скрипт сам проверит Node.js и Python,
поставит Claude Code, выполнит вход по подписке, установит зависимости,
спросит токен бота, сам определит ваш Telegram ID и запустит Jarvis.

Дальше для запуска — **`start.bat`**.

Заранее нужны только [Node.js](https://nodejs.org) и
[Python](https://www.python.org/downloads/); если их нет, скрипт скажет об этом
и даст ссылки.

## Установка вручную (macOS, Linux или если хочется контроля)

```bash
# 1. Claude Code CLI и вход по подписке
npm install -g --allow-scripts=@anthropic-ai/claude-code @anthropic-ai/claude-code
claude auth login

# 2. Зависимости бота
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. Настройки
cp .env.example .env
```

В `.env` заполните `TELEGRAM_BOT_TOKEN` (токен от [@BotFather](https://t.me/BotFather))
и `JARVIS_OWNER_IDS`. Свой ID можно не искать заранее: поставьте временно `0`,
запустите бота, отправьте ему `/id` — он ответит числом, его и впишите.

## Запуск

```bash
python -m jarvis
```

Бот работает, пока запущен процесс. Для постоянной работы — systemd-юнит,
`screen`/`tmux` или любой супервизор на машине, где вы выполнили `claude auth login`.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | приветствие и справка |
| `/new` | очистить контекст, начать разговор заново |
| `/stop` | прервать текущую работу агента |
| `/id` | показать ваш Telegram ID |

Обычный текст — это запрос к Jarvis. Контекст держится в рамках чата, пока не
скажете `/new`.

## Что умеет

**Присылает файлы.** Всё, что Claude сохранит в рабочей папке, бот отправляет
в чат следующим сообщением: презентации, таблицы, документы. Работает через
встроенные навыки Claude Code (`pptx`, `xlsx`, `docx`, `pdf`), поэтому в
`JARVIS_ALLOWED_TOOLS` нужен `Bash` — навыки собирают документы скриптами.
Подпапка `tmp` не отправляется: там черновики. Потолок Telegram — 50 МБ на файл.

**Понимает голосовые.** Распознавание идёт локально через
[faster-whisper](https://github.com/SYSTRAN/faster-whisper) — без API-ключей,
без интернета и без доплат. Первое голосовое скачивает модель (~0.5 ГБ для
`small`), дальше работает сразу. Расшифровку бот показывает в чате, чтобы было
видно, что он услышал. Отключается через `JARVIS_WHISPER_MODEL=`.

**Помнит разговор.** Сессия Claude сохраняется в `sessions.json` и продолжается
после перезапуска бота и перезагрузки компьютера — бессрочно
(`JARVIS_MEMORY_DAYS=0`). Длинная история со временем сжимается в пересказ, это
устройство самого Claude; поэтому важные факты Jarvis дублирует дословно в
`tmp/memory.md` и сверяется с ним. Файл заметок переживает даже `/new`.

## Настройки

Все параметры — переменные окружения (см. `.env.example`):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен бота, обязателен |
| `JARVIS_OWNER_IDS` | — | ID через запятую, обязателен |
| `JARVIS_WORKSPACE` | `./workspace` | песочница для файлов |
| `JARVIS_MODEL` | из Claude Code | модель |
| `JARVIS_PERMISSION_MODE` | `acceptEdits` | режим разрешений |
| `JARVIS_ALLOWED_TOOLS` | Read, Write, Edit, Glob, Grep, Bash, WebSearch, WebFetch | разрешённые инструменты |
| `JARVIS_MEMORY_DAYS` | `0` | срок памяти в днях; 0 — бессрочно |
| `JARVIS_WHISPER_MODEL` | `small` | модель распознавания речи; пусто — выключить |
| `JARVIS_MAX_FILES` | `5` | сколько файлов отправлять за один ответ |
| `JARVIS_SHOW_TOOLS` | `1` | дописывать список использованных инструментов |
| `JARVIS_MAX_TURNS` | — | лимит шагов на один запрос |
| `JARVIS_MAX_BUDGET_USD` | — | лимит бюджета на один запрос |
| `JARVIS_PERSONA` | встроенная | системная надстройка над промптом Claude Code |

## Безопасность

- `Bash` входит в список разрешённых инструментов — без него Claude не может
  собирать презентации и таблицы. Это означает, что бот выполняет команды на
  вашей машине. Если презентации не нужны, уберите `Bash` из
  `JARVIS_ALLOWED_TOOLS`.
- Файловые инструменты ограничены рабочей папкой (`cwd` агента).
- `.env` и `workspace/` в `.gitignore` — токен и рабочие файлы в репозиторий
  не попадут.

## Структура

```
jarvis/
  __main__.py   точка входа, проверка CLI и снятие API-ключей
  config.py     конфигурация из окружения, персона по умолчанию
  agent.py      сессии Claude Agent SDK, одна на чат
  bot.py        Telegram: команды, обработчики, разбиение длинных ответов
  outbox.py     какие файлы из рабочей папки отправить в чат
  store.py      память: сессии переживают перезапуск
  voice.py      распознавание голосовых через локальный Whisper

install.bat     установка в один щелчок (Windows)
start.bat       запуск после установки (Windows)
setup.ps1       что именно делает install.bat
```
