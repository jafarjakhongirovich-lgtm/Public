# Jarvis

Личный ассистент в Telegram на **Claude Agent SDK**, работающий через вашу
подписку Claude — без API-ключа и без оплаты за токены.

## Как устроена авторизация

Agent SDK не ходит в API сам: он запускает локальный Claude Code CLI, а тот
берёт OAuth-токен из `claude auth login`. То есть бот использует ровно ту же
авторизацию, что и ваш `claude` в терминале — вашу подписку.

Единственное, что может это сломать — переменная `ANTHROPIC_API_KEY` в
окружении: при ней CLI переключится на оплату по ключу. Поэтому `jarvis`
снимает `ANTHROPIC_API_KEY` и `ANTHROPIC_AUTH_TOKEN` при старте и пишет об
этом в лог.

> Подписочный вход разрешён для вашего личного использования. Раздавать доступ
> к такому боту посторонним нельзя — поэтому `JARVIS_OWNER_IDS` обязателен, и
> всем остальным бот просто отказывает.

## Установка

```bash
# 1. Claude Code CLI и вход по подписке
npm install -g @anthropic-ai/claude-code
claude auth login

# 2. Зависимости бота
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. Настройки
cp .env.example .env
```

В `.env` заполните `TELEGRAM_BOT_TOKEN` (токен от [@BotFather](https://t.me/BotFather))
и `JARVIS_OWNER_IDS`. Свой ID можно не искать заранее: поставьте временно `0`,
запустите бота, отправьте ему `/id` — он ответит числом, его и впишите.

## Запуск

```bash
python -m jarvis
```

Бот работает, пока запущен процесс. Для постоянной работы — systemd-юнит,
`screen`/`tmux` или любой супервизор на машине, где вы выполнили `claude auth login`.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | приветствие и справка |
| `/new` | очистить контекст, начать разговор заново |
| `/stop` | прервать текущую работу агента |
| `/id` | показать ваш Telegram ID |

Обычный текст — это запрос к Jarvis. Контекст держится в рамках чата, пока не
скажете `/new`.

## Настройки

Все параметры — переменные окружения (см. `.env.example`):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен бота, обязателен |
| `JARVIS_OWNER_IDS` | — | ID через запятую, обязателен |
| `JARVIS_WORKSPACE` | `./workspace` | песочница для файлов |
| `JARVIS_MODEL` | из Claude Code | модель |
| `JARVIS_PERMISSION_MODE` | `acceptEdits` | режим разрешений |
| `JARVIS_ALLOWED_TOOLS` | Read, Write, Edit, Glob, Grep, WebSearch, WebFetch | разрешённые инструменты |
| `JARVIS_SHOW_TOOLS` | `1` | дописывать список использованных инструментов |
| `JARVIS_MAX_TURNS` | — | лимит шагов на один запрос |
| `JARVIS_MAX_BUDGET_USD` | — | лимит бюджета на один запрос |
| `JARVIS_PERSONA` | встроенная | системная надстройка над промптом Claude Code |

## Безопасность

- `Bash` в список разрешённых инструментов **не** входит. Добавляйте, только
  если сознательно готовы к тому, что бот сможет выполнять команды на машине.
- Файловые инструменты ограничены рабочей папкой (`cwd` агента).
- `.env` и `workspace/` в `.gitignore` — токен и рабочие файлы в репозиторий
  не попадут.

## Структура

```
jarvis/
  __main__.py   точка входа, проверка CLI и снятие API-ключей
  config.py     конфигурация из окружения, персона по умолчанию
  agent.py      сессии Claude Agent SDK, одна на чат
  bot.py        Telegram: команды, обработчики, разбиение длинных ответов
```
