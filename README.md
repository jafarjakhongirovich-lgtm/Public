# Machos.uz — 3D-сайт продукции

Одностраничный рекламный сайт снек-бренда **Machos.uz** — шесть позиций:
семечки, курт трёх форм, сырные палочки и сырная косичка.

Пачка товара — настоящая 3D-модель на Three.js, собранная по форме реальной
упаковки: флоу-пак с плоским швом по краям, отверстием-подвесом, печатной
шапкой и **прозрачным окном**, через которое виден сам продукт — кубики,
шарики, батончики, палочки или косичка. При выборе товара меняется форма
пачки, печать, содержимое и акцентный цвет всего сайта.

## Запуск

Сайт полностью статический и не требует сборки:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Открывать `index.html` двойным кликом **нельзя** — браузер заблокирует
ES-модули по протоколу `file://`. Нужен любой локальный сервер (команда выше,
`npx serve`, Live Server в VS Code) или обычный хостинг.

## Структура

```
index.html          весь сайт: разметка, стили, 3D-сцена
vendor/three/       Three.js r169 (лежит в репозитории, CDN не нужен)
assets/             сюда кладутся фото пачек, если они появятся
```

Three.js положен в репозиторий намеренно: сайт работает без интернета и не
зависит от доступности CDN. Единственный внешний запрос — шрифты Google Fonts
(Unbounded + Inter); если они не загрузятся, подставятся системные.

## Что и где менять

Всё содержимое лежит в начале `<script type="module">` в `index.html`:

| Что | Где |
| --- | --- |
| Товары: названия, цвета пачек, состав, вес | массив `PRODUCTS` |
| Телефон, почта, сайт, производитель | объект `CONTACTS` |
| **Ссылка на Facebook**, Instagram, Telegram | `CONTACTS.socials` |
| Бегущая строка | массив `TICKER` |
| Остальные тексты | прямо в HTML-разметке секций |

### Ссылки на соцсети

```js
socials: [
  { name:'Facebook',  url:'' },   // ← вставьте сюда ссылку
  { name:'Instagram', url:'' },
  { name:'Telegram',  url:'' },
],
```

Пока `url` пустой, кнопка показывается приглушённой и не кликается — место под
ссылку видно, но посетитель никуда не уйдёт. Как только вписали адрес, кнопка
становится активной сама.

### Фото пачек

Сейчас этикетки **рисуются в браузере** по данным из `PRODUCTS` — по мотивам
реальной упаковки. Это приближение, а не точная копия.

**Чтобы пачки были точь-в-точь как настоящие**, положите изображения в папку
`assets/` с такими именами — код подхватит их сам, ничего править не нужно:

| Файл | Товар |
| --- | --- |
| `assets/seeds.png` | семечки Pista Tuzli |
| `assets/kurt-cube.png` | курт кубиками |
| `assets/kurt-ball.png` | курт шариками |
| `assets/kurt-stick.png` | курт палочками |
| `assets/sticks.png` | сырные палочки |
| `assets/braid.png` | сырная косичка |

Проверяются `.png`, затем `.jpg`. Если файла нет, остаётся нарисованный макет,
так что сайт не сломается. Другой формат или имя задаются через поле `photo`.

Что именно класть, по убыванию качества результата:

1. **Макет упаковки от типографии** (PDF/AI/CDR → экспорт в PNG) — даёт
   идеальный результат: ровная лицевая сторона без бликов и перспективы.
2. Фото пачки строго анфас, на белом фоне, без вспышки и наклона, обрезанное
   ровно по краям пачки.

Снимок пачки на столе под углом со бликами использовать не стоит — на 3D-модели
он ляжет вместе с фоном и перспективой. Пропорции картинки лучше держать
близкими к пропорциям самой пачки (`size` в `PRODUCTS`).

Через `photo` можно задать и произвольный путь:

```js
{ id:'kurt', photo:'assets/kurt-front.png', ... }
```

### Форма заявки

Форма в секции «Оптом» **не подключена к серверу** — она проверяет поля и
показывает подтверждение. Точка подключения помечена в коде:

```js
// TODO: подключить отправку —
// fetch('/api/lead', { method:'POST', body:new FormData(form) })
```

Подойдёт любой обработчик: свой бэкенд, Telegram-бот, Formspree и т. п.
Подпись «Демо-режим» под формой нужно убрать после подключения.

## Поддержка браузеров и доступность

- Если WebGL недоступен или скрипт не загрузился, через 7 секунд включается
  плоская запасная версия — посетитель не остаётся перед пустым экраном.
- При системной настройке «уменьшить движение» анимации и вращение отключаются.
- Навигация с клавиатуры, `aria`-атрибуты у меню и переключателя продуктов,
  ссылка «Перейти к содержимому» в начале страницы.
- На узких экранах пачка поднимается над текстом и приглушается, чтобы
  содержимое оставалось читаемым.

## Один файл для отправки

`dist/machos.html` — вся страница вместе со встроенным Three.js в одном файле.
Открывается двойным кликом, работает без интернета, кладётся на любой хостинг
как есть. Пересобирается после правок `index.html`:

```bash
python3 build-standalone.py
```

Фото пачек из `assets/` в этот файл **не попадают** — они грузятся рядом с
`index.html`. Для полноценного сайта с фото публикуйте папку целиком.

## Публикация

ветки — сборка не нужна.
