# Machos.uz — сайт продукции

Одностраничный сайт снек-бренда **Machos.uz**: курт четырёх форм, сырные палочки,
сырная косичка и солёные семечки. Формы заявки на сайте нет — все обращения
идут через телефон. Чёрно-жёлтая гамма взята с упаковки, товар
показан настоящими фотографиями с вырезанным фоном, пачка выбранного продукта
висит в 3D-сцене и поворачивается за курсором.

Интерфейс на **двух языках — русском и узбекском**, переключатель в шапке,
выбор запоминается.

## Запуск

Сайт статический, сборка не нужна:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Открывать `index.html` двойным кликом нельзя — браузер заблокирует ES-модули по
протоколу `file://`. Нужен локальный сервер (команда выше, `npx serve`,
Live Server в VS Code) или обычный хостинг.

## Структура

```
index.html            весь сайт: разметка, стили, тексты, 3D-сцена
assets/               фотографии товара с вырезанным фоном (.webp)
vendor/three/         Three.js r169 — лежит в репозитории, CDN не нужен
dist/machos.html      сборка одним файлом
build-standalone.py   собирает dist
```

Единственный внешний запрос — шрифты Google Fonts (Rubik + Manrope); если они не
загрузятся, подставятся системные.

## Что и где менять

Всё содержимое лежит в первом `<script>` внутри `index.html`:

| Что | Где |
| --- | --- |
| Товары: названия, описания, вес, состав | массив `PRODUCTS` |
| Телефоны, почта, адрес | объект `CONTACTS` |
| **Ссылка на Facebook**, Instagram, Telegram | `CONTACTS.socials` |
| Тексты интерфейса на обоих языках | объект `I18N` |
| Бегущая строка | объект `TAPE` |
| Категории фильтра | массив `CATS` |

### Два языка

Каждый видимый текст помечен атрибутом `data-i18n="ключ"`, перевод берётся из
`I18N.ru` и `I18N.uz`. Чтобы поправить надпись, найдите ключ и измените обе
строки. У товаров переводы лежат прямо в карточке (`ru` и `uz`).

### Ссылки на соцсети

```js
socials: [
  { name:'Facebook',  url:'https://www.facebook.com/share/1HkTk4ZkMF/' },
  { name:'Instagram', url:'https://www.instagram.com/machos_uz' },
  { name:'Telegram',  url:'' },   // ← ссылки пока нет, кнопка приглушена
],
```

Пока `url` пустой, кнопка показывается приглушённой и не кликается: место под
ссылку видно, но посетитель никуда не уйдёт.

### История компании

Раздел «История» собирается из массива `HISTORY`: четыре вехи, у каждой
заголовок и абзац на двух языках. Год выводится, только если поле `year`
заполнено — сейчас указан лишь `2012`, у остальных вех поле пустое.

```js
{ year:'2012', ru:{ h:'Начал один', p:'…' }, uz:{ h:'…', p:'…' } },
```

Даты от заказчика: 2012 — начало в Ташкенте в одиночку, 2013 — открытие
цеха, начало февраля 2014 — наём работников. Поле `year` принимает либо
строку (`'2013'`), либо пару переводов (`{ru:'…', uz:'…'}`) — так сделана
дата с названием месяца.

### Консультация и бонусы

Кнопка «Консультация» в шапке открывает окно: три шага работы представителя
и лестница бонусов за объём заказа. Всё настраивается в объекте `CONSULT`:

```js
tiers: [
  { sum:200000,  kind:'min', ru:'Минимальная сумма заказа', uz:'…' },
  { sum:500000,  ru:'Скидка 5%',  uz:'5% chegirma' },
  { sum:750000,  ru:'Скидка 10%', uz:'10% chegirma' },
  { sum:1000000, kind:'top', ru:'Фирменная стойка в подарок', uz:'…' },
]
```

`kind:'min'` помечает нижнюю ступень (сумма показывается как «от …»),
`kind:'top'` подсвечивает верхнюю жёлтой рамкой. Суммы в сумах, порядок —
по возрастанию, разряды расставляются сами.

### Фотографии товара

Фото ищется по имени `assets/<id>.webp` (а также `.png`, `.jpg`, `.jpeg`).
**Позиция без фотографии на сайте не показывается** — сейчас так скрыты
семечки. Она вернётся в список сама, как только файл появится.

| Файл | Товар |
| --- | --- |
| `assets/seeds.webp` | семечки Pista Tuzli — **нет, позиция скрыта** |
| `assets/kurt-cube.webp` | курт кубиками |
| `assets/kurt-ball.webp` | курт шариками |
| `assets/kurt-stick.webp` | курт палочками |
| `assets/kurt-big.webp` | курт крупными кусками |
| `assets/kurt-ball-12.webp` | курт шариками, большая пачка |
| `assets/sticks-cyan.webp` | сырные палочки, бирюзовая упаковка |
| `assets/braid-green.webp` | сырная косичка, зелёная упаковка |
| `assets/sticks.webp` | сырные палочки |
| `assets/braid.webp` | сырная косичка |

Фон у снимков вырезан: контур строится по печати на упаковке, поэтому пачка
висит в сцене силуэтом, а не прямоугольной плиткой. Новые фотографии нужно
обрабатывать так же — снимок с фоном на тёмном сайте выглядит заплаткой.

## Данные, которые стоит проверить

- телефон `+998 95 194 55 15` — единственный номер на сайте; он же стоит
  как номер отдела продаж (`phone2`), поэтому вторая строка в контактах
  скрыта: она появится сама, когда номера станут разными. Почта `info@machos.uz`, адрес
  ООО «FUN NUTS GROUP», Ташкент, Шайхантахурский район, пр. Гормонский, 3А —
  прочитаны с упаковки;
- вес от заказчика: курт кубиками и шариками 30 ± 5 г, большая пачка
  шариков и курт палочками по 48 г, сырные палочки в бирюзовой упаковке
  60 г; семечки 200 г с пачки. У курта крупными кусками, жёлтых сырных
  палочек и обеих косичек вес не заполнен — строка «Вес» в карточке просто не показывается;
- «100% натуральный состав» на первом экране — заготовка. Число позиций
  рядом считается по каталогу само и правки не требует.

## Доступность и запасной вариант

- Если WebGL недоступен, вместо сцены показывается обычная фотография.
- При системной настройке «уменьшить движение» анимации отключаются.
- Навигация с клавиатуры, `aria`-атрибуты у меню, фильтра и переключателя
  языка, ссылка «Перейти к содержимому» в начале страницы.
- На узких экранах сцена приглушается, чтобы текст оставался читаемым.

## Один файл для отправки

`dist/machos.html` — вся страница вместе со встроенным Three.js и
фотографиями. Открывается двойным кликом, работает без интернета, кладётся на
любой хостинг как есть. Пересобирается после правок:

```bash
python3 build-standalone.py
```

Любой статический хостинг. Для GitHub Pages достаточно включить Pages для этой
