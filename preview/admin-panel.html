Система учёта рабочего времени по QR

Сотрудник сканирует QR-код с экрана в офисе — время прихода и ухода попадает в базу, а в конце месяца система считает зарплату с учётом опозданий. Ниже — настоящие экраны системы, заполненные демо-данными за июль 2026.

Это статичный снимок, а не работающая система. Кнопки и формы здесь ничего не сохраняют, а QR-код показан одним кадром — его токен давно истёк. Рабочая версия запускается у вас на компьютере: код и инструкция в репозитории. Интерфейс на узбекском — так его видят сотрудники; подписи вокруг я перевёл.

Экран в офисе

Висит у входа на телевизоре, мониторе или старом планшете. Сотрудник наводит камеру телефона — открывается Telegram, время фиксируется. Ничего вводить и никуда входить не нужно.

Telefon kamerasi bilan skanerlang — Telegram o'zi ochiladi va kelgan/ketgan vaqtingiz yoziladi. QR har 15 sekundda yangilanadi.

  • 15 секКод на экране обновляется каждые 15 секунд, а токен живёт 25 — сфотографировать его и отметиться из дома не получится.
  • 1 разКаждый токен срабатывает только один раз: переслать код коллеге бессмысленно.
  • HMACТокен подписан ключом сервера, поэтому сгенерировать свой нельзя.
  • ЧестноСлабое место есть: если сотрудник по видеозвонку попросит коллегу показать экран в прямом эфире — это система не поймает. Для такого нужна камера с распознаванием лица.

Как запустить у себя

VPS не нужен. Бот сам звонит в Telegram, а страницу с QR открывает только экран в офисе — значит хватит обычного компьютера в локальной сети. Нужен Python 3.11 или новее.

  1. Скачать код и поставить библиотеки

    # в папке с проектом
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt   // Windows
.venv/bin/pip install -r requirements.txt        # macOS, Linux

  2. Создать файл настроек

    Скопируйте .env.example в .env и впишите секретный ключ — его сгенерирует команда python manage.py secret.

  3. Посмотреть на демо-данных

    Токен бота для этого не нужен — появятся те же шесть сотрудников, что и на этой странице.

    python manage.py demo --period 2026-07
python -m uvicorn app.main:app --port 8000

    Панель откроется на http://localhost:8000/admin, а ссылку на экран с QR напечатает команда python manage.py kiosks.

  4. Подключить бота, когда будете готовы

    Токен выдаёт @BotFather в Telegram по команде /newbot. Впишите его и имя бота в .env, запустите python -m app.bot — и QR начнёт работать по-настоящему.

  5. Очистить демо-данные перед реальной работой

    Удалите файл базы tabel.db и выполните python manage.py init. Затем добавьте настоящих сотрудников и праздники: python manage.py holidays --year 2026.

Данные на странице — вымышленные, созданы командой manage.py demo. Цифры считает тот же код, что работает в реальной системе, поэтому расчёты настоящие. Исходный код и подробная инструкция — в репозитории на GitHub.
